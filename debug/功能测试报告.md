## 一、已实现的功能 ✅

### 1.1 数据库重置功能
- **文件位置**：[scripts/reset-parsed-results.mjs](../scripts/reset-parsed-results.mjs)
- **SQL脚本**：[sql/reset-parsed-results.sql](../sql/reset-parsed-results.sql)
- **功能描述**：
  - 可以重置所有解析结果（proto_events、events、event_news等）
  - **保留**原始新闻数据（news表）
  - 支持CLI和API两种调用方式
  - 有确认机制防止误操作

### 1.2 事件聚类功能
- **文件位置**：[lib/analysis/canonical-merger.mjs](../lib/analysis/canonical-merger.mjs)
- **数据库字段**：proto_events.canonical_event_id
- **功能描述**：
  - 每个原子事件（proto_event）都会关联到标准事件（event）
  - 在保存proto_event时直接设置canonical_event_id
  - 通过外键约束保证数据一致性
  - 提高查询效率

### 1.3 管理员API
- **文件位置**：[api/v1/admin.mjs](../api/v1/admin.mjs)
- **已实现的接口**：
  - `POST /api/v1/admin/reset-parsed` - 重置解析结果
  - `POST /api/v1/admin/reparse-all` - 批量重新解析
  - `POST /api/v1/admin/reparse/:id` - 重新解析单个新闻
  - `GET /api/v1/admin/parse-status` - 检查解析状态

### 1.4 一致性检查工具
- **文件位置**：[scripts/check-consistency.mjs](../scripts/check-consistency.mjs)
- **功能**：
  - 检查proto_events.canonical_event_id字段是否存在
  - 统计关联率
  - 自动修复功能
- **使用方式**：
  - `npm run check-consistency` - 检查
  - `npm run fix-consistency` - 修复

## 二、发现并修复的问题 🔧

### 2.1 问题1：reset-parsed-results.mjs API调用时的交互确认
**问题描述**：
- 原脚本在API调用时仍要求用户输入"YES"确认
- API模式下无交互能力，导致程序卡住

**修复方案**：
- 添加 `skipConfirm` 参数
- API调用时传递 `true` 跳过确认
- 错误处理优化：API模式下抛出错误而非process.exit

**文件**：[scripts/reset-parsed-results.mjs](../scripts/reset-parsed-results.mjs)

### 2.2 问题2：admin.mjs 参数解析问题
**问题描述**：
- `/reparse-all` 接口只从 req.body 读取参数
- 不支持通过 query string 传递参数（如示例中的 `?page=1&limit=50`）

**修复方案**：
- 合并 req.body 和 req.query
- 优先使用 body 参数

**文件**：[api/v1/admin.mjs](../api/v1/admin.mjs)

### 2.3 问题3：admin.mjs 缺少导入
**问题描述**：
- 调用了 `extractProtoEventsWithLLM` 但未导入

**修复方案**：
- 添加导入：`import { extractProtoEventsWithLLM } from '../../apis/parsers/llm-parser.mjs';`

**文件**：[api/v1/admin.mjs](../api/v1/admin.mjs)

## 四、使用方法 🚀

### 4.1 数据库重置
**方式一：CLI命令**
```bash
npm run reset-parsed
```

**方式二：API调用**
```bash
curl -X POST http://localhost:3118/api/v1/admin/reset-parsed
```

### 4.2 重新解析
**批量重新解析**
```bash
curl -X POST http://localhost:3118/api/v1/admin/reparse-all?page=1&limit=50
```

**单个新闻重新解析**
```bash
curl -X POST http://localhost:3118/api/v1/admin/reparse/123
```

### 4.3 一致性检查
```bash
npm run check-consistency
npm run fix-consistency
```

### 4.4 查看解析状态
```bash

```
